UrbanETA-NYC

A machine learning model and interactive web app that estimate New York City taxi trip durations from pickup and drop-off details.

  • View on GitHub
  • Live demo

My contribution

I prepared features for pickup time, location clusters, and distances that account for the city grid. I compared regression baselines with XGBoost and deployed the chosen model as a Streamlit app, where visitors can enter trip details to get a duration estimate.

Tools used

  • Python
  • pandas
  • NumPy
  • scikit-learn
  • XGBoost
  • Streamlit
